# Спрайты игры

Загрузчик читает PNG из `custom/`, затем применяет набор `custom/radiant/`.
Герои и значки интерфейса находятся в базовой папке; окружение и текущие
предметы — в `radiant/`. PNG и шрифт встраиваются в игру.

## Формат

- `<роль>.png` — статичный спрайт; `<роль>.N.png` — N кадров по горизонтали.
  Число означает количество кадров, а не версию.
- Клетка движения — 32×32 px. Герои привязаны к середине нижней грани клетки.
- Для окружения четыре кадра — пространственные варианты, не анимация.
  `meadow` и `trail` состоят из четырёх смежных квадрантов цельной текстуры.
- Предметы имеют прозрачный фон и размер 32×32; портал — 56×64.

## Активные роли

| Роль | Назначение |
|------|------------|
| `player` | Juggernaut, 8 кадров |
| `pudge`, `bloodseeker`, `riki`, `axe`, `skywrath` | Враги: 8, 21, 39, 48 и 5 кадров соответственно |
| `food`, `elixir`, `scroll`, `sword` | Tango, Clarity, TP Scroll и клинок Juggernaut; эффекты предметов не менялись |
| `portal` | Замшелый портал с голубым свечением, выход на следующий уровень |
| `floor` | Почва под лесом, кадр 32×32 |
| `meadow`, `trail` | Трава полян и тропы, квадранты 128×128 |
| `tree` | Деревья, кадр 96×128 |
| `ruins` | Каменные руины, кадр 64×80 |
| `bush`, `decor` | Кусты 48×40 и малые растения 32×32 |
| `verge`, `moss` | Растительная кромка 64×32 и мох 128×64 |
| `heart`, `ui_run` | Значки здоровья и бега |

Предметы и герои на поле получают тёмную обводку 1 px и усиление яркости
на 12%; иконки интерфейса и портреты остаются без этого эффекта.
Персонажи рисуются по положению ног: кто ниже, тот впереди. При одинаковой
высоте сохраняется порядок врагов, игрок рисуется последним.
Мешающие участки гейта локально становятся полупрозрачными, не закрывая
видимые предметы и героев. Неоткрытые объекты не отображаются.

Финальные исходники находятся в [docs/art/radiant](../../../docs/art/radiant).
Их упаковывают `tools/terrainpack` и `tools/itempack`; большие исходники
не встраиваются в бинарник. `tools/terrainpreview` снимает кадры настоящего
рендерера в локальной сцене без сетевых запросов и отправки рекордов.
